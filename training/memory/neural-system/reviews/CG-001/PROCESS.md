# CG-001 固定面板：真实自由生成与独立评审

结论：**第 50 步候选未通过，不继续加步数，不部署。**
这是两个开发世界、中英双语、单个给定事件的 16 条组件面板，不是 LoCoMo 或完整自动记忆系统。

## 固定实验与身份

先冻结 `experiments/CG-001-step50-generation.json`，再生成；没有调整样例、分母、
greedy 解码、GGUF ChatML 模板或 32-token 上限。baseline/step50 原始报告保留在本目录。
检查点完整 SHA-256：`a8976841239f18520842e75551dfbc8681c27f6d25e0784fed03c1efcb5585d9`。
训练及测试均绑定同一 0.5B GGUF；无 LoRA、SVD/NAS、backbone 更新或 LoCoMo 选模。

第 50 步生成共 168 个位置、504 次真实 C 前向，全部完成 EOS，无截断/无效 UTF-8。
每个位置重新创建 context、完整 prefill；普通 C 参考与连续分支的基础 hidden/logits 逐位一致。
无跨 token/request KV 复用；单次 prefill 内仍有 attention K/V 工作缓冲。
神经融合在 Python，C 执行冻结 backbone 与连续输出投影；不是完整 C 神经模块或 HTTP 链路。
来源通过独立编码进入神经分支，不进入生成 prompt，不检索、不读取教师强制答案前缀库。

首次生成报告沿用了通用 transport 的 `backend_cache_policy_verified: false` 默认值，
未把已经执行的具体后端校验写回此字段。原始报告未改写；`native-audit.json` 独立检查
全部 raw SHA-256、每步两份 fresh-context trace、普通 C 参考标志及预测前缀连续性，全部通过。
后续 evaluator 已修正该报告字段；这不是启用过 KV 后修改标记，也没有改动实际生成文本。

## 双评审过程

操作者曾先用原校准评审实例标注基线，记录仍在 build 中；那些票不用于本目录最终得分。
最终将基线与候选混合、移除模型/步数/数据场景身份、按 opaque ID 排序，
交给两个全新、互不共享上下文的模型评审实例 `/root/cg001_judge_a` 和 `/root/cg001_judge_b`。
它们只收到 `blind.json` 和相同语义标注规范，没有读取标签、代码、模型或对方结果。
模型同源，不能宣称真人或跨模型家族验证；这种相关偏差限制仍存在。

32 个输入-回复记录中，3 个在两种条件下完全相同，形成 **29 个唯一盲包**，两位各标注 29 个。
相同上下文和相同回复复用同一标注；每个实验仍独立保留完整 16 条分母。
29/29 的语义标注签名一致；无缺失或分歧待审。评审只提取实际声称的事实及话语属性，
由冻结 rubric 计算正确性。裸 “Ok.” 是自然表达但无算术结论；New York/City 保留原文区别；
网站或地图建议不被误提取成居住事实。没有为提高得分修改两位原始标注。

## 结果

| 同一固定面板 | 无记忆基线 | 第 50 步 |
| --- | --- | --- |
| 全部回复通过 | 3/16 | 1/16 |
| 有记忆问答（原值 + 换值） | 0/8 | 0/8 |
| 空记忆恰当承认未知 | 1/4 | 1/4 |
| 普通算术正确 | 2/4 | 0/4 |
| 换值成对通过（两端都正确） | 0/4 | 0/4 |
| 移除记忆成对通过（两端都正确） | 0/4 | 0/4 |

不能把 1/16 或教师强制 NLL 改善叫作新的系统记忆准确率。唯一通过的是一个空库拒答，
没有有依据 recall 的成功案例。中文普通聊天退化已触发停止条件。

典型原始证据：

- Celia 的来源从 Turin 换为 Graz，英文两次都答 `Celia currently lives in New York.`。
- Adela 的来源从 Rennes 换为 Turin，英文两次都答 `Adela is currently living in Berlin.`。
- 有正确来源的四条中文问答全部变成无法提供信息的回复。
- 中文 `3 + 31` 从基线的 34 变为 64；`2 + 30` 从 32 变为 6。

## 原因证据及其边界

1. **不是目前观察到的 C/Torch 投影偏差。** 所有初始位置的残差精确重放，
   16/16 初始位置的实际 C/Torch correction/logits 均通过原定 `atol=1e-5, rtol=1e-4`，
   top-1 一致，最大 logit 误差 `4.2915e-6`。这是初始位置对照，不宣称全 168 位置 Torch 对照。
2. **控制与生成目标存在局部冲突。** 同一检查点上，完整回复 CE 与加权初始状态 CE
   对状态头的梯度在 11/16 条相反，其中 8/8 有证据样例全部相反。
   两条中文普通聊天的相反梯度规模接近；该诊断没有优化器步骤。
3. **内容路径明显偏弱。** 内容 gain 的 tanh 仅约 0.003759；8 条有证据问答的初始位置，
   不确定分支加权 hidden 残差范数约为内容分支的 41–610 倍。
   范数不是因果贡献度，尚需分支消融，不能只据此断言唯一根因。
4. **初始分类正确没有贯穿生成。** 8 条有证据问答初始都判为有证据，
   之后的 82 个生成位置全部改变了三状态 argmax。只在初始位置监督状态、
   却在每个回答 token 重判，与最终设计要求的本轮只读决策尚未对齐。

这些发现足以阻止继续堆步数，但不证明神经记忆整体设计不可能成功，也不能排除
数据覆盖、主体绑定、训练时长及最终输出融合表达能力的其他限制。
