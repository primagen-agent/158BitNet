# DG-028：表征线性可分性探针（零更新）

结论：**route信息部分存在但r1↔r2纠缠；按注册判定规则落在"表征需改"一侧（边界值）。**
注册：`../../experiments/DG-028.json`；检查：`checks/DG-028-probe.json`。冻结V3-002 reader（摘要前后核验一致）。

## 结果（独立logistic探针，5折CV，892项，与route头完全相同的输入向量）

| 类 | 训练头实际recall | 新探针recall |
| --- | ---: | ---: |
| r0 normal | 0.50 | **0.97** |
| r1 supported | 1.00 | 0.45 |
| r2 insufficient | 0.18 | **0.45** |

- r0几乎完全可分（无来源/无跨度的结构信号在表征里且线性可读——训练头只用了一半）；
- **r1↔r2纠缠**：平衡探针把r2从0.18提到0.45的代价是r1降到0.45——同一表征上二者不可同时线性读出，
  印证"都有来源与跨度、只差事实存在性"的结构故事；
- 探针r2=0.451，注册阈值<0.5判"表征缺信息"；考虑r0=0.97的强对比，诚实的读法是：
  **r0可分、r1/r2边界处表征信息不足**（0.451紧贴0.5边界，按规则落在表征侧，如实标注边界性）。
