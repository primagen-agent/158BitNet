以下都是在原轨迹上的局部对照，不是替代策略的端到端准确率：

| 单独干预 | 改变下一词选择的位置 |
| --- | --- |
| 移除内容增量 | 0/168 |
| 移除不确定增量 | 33/168 |
| 固定首轮状态概率，仍保留当前 token 的生成特征 | 12/168 |

8 条有证据问答的初始位置，不确定分支的 **logit 增量范数**约为内容分支的 18–390 倍。
这与此前 hidden 范数约 41–610 倍是不同指标。移除内容没有改变这组轨迹上的 greedy 选择，
不代表它在所有输入上恒为零，也不证明移除它后泛化能力更好。

生成梯度隔离对照：16/16 条的 logits 与原模型完全一致，`state_encoder` 和 `state_head`
的生成梯度为零；状态 CE 仍能训练分类器，内容/不确定输出矩阵在结构允许时仍有非零有限梯度。
这是人为指定的分模块优化规则，不是原联合目标的完整导数，也不是准确率改进。
共享 reader 仍会改变分类器输入，不能声称所有任务相互独立。

初始化对照：原始零 gain 时，内容输出矩阵的首步生成梯度为零，但 **gain 自身梯度非零**，
所以不是永久死通路。改成末层 gain 参数为 1、内容输出矩阵为零，两种初始化仍都精确保留基础 logits；
12 个非空来源样例的内容输出矩阵从首步即可获得梯度（约 0.112–0.165），空来源仍为零。
这只证明替代初始化可以学习，不证明学得更好；两个分支的梯度尺度也未完全相等。

直接给旧检查点固定首轮门控并未改善教师强制损失：

| 样例类别 | 原 NLL | 固定首轮概率后的 NLL |
| --- | ---: | ---: |
| 有证据（8 条） | 2.7370 | 3.5604 |

改变推理规则后必须用一致的训练规则重新验证，不能直接部署旧权重。

## 设计判断

更重要的问题是职责约束：原生成 loss 可从不确定分支降低完整回答 NLL，
而该分支又接受含来源信息的状态特征，导致“证据不足”这个名字并不限制它承担事实/风格生成。
仅 detach 门控仍保留这个取巧路径；仅固定门控也未使已有内容路径变好。

另一个明确的不一致是：无需记忆路线按定义保持 backbone，但普通样例的参考答案 CE
又要求它修正 backbone 的错误或输出另一种措辞。例如基线英语算术只答 Ok，却要求零增量路线答出数字。
两项目标无法同时精确满足。**不能靠调大分类 loss 权重代替修正目标本身。**

因此下一候选要把三条职责和监督分开：

1. 用户 prefill 上预测本轮状态，生成期间不重判任务状态。
2. 内容分支专门学习依据记忆生成；不确定分支不接收来源值特征，只学习缺证据时的自然回应。
3. 普通聊天不再用参考答案 CE 逼记忆模块修理通用模型，改为保持基础分布；
   正确/错误的基础回答都照原 rubric 如实评分，不修改基线答案或评测分母。

候选模型、监督接口、初始数值与 CUDA 预检查尚未实现/放行，本轮 **0 个 optimizer step**。
