# CG-002：职责分离模型与首段训练

这是单个给定事件的研究候选，不是完整 writer/多事件 reader，不替换部署系统。
实验配置：`experiments/CG-002.json`。本候选占既定两种方案预算的第二种，不暗中继续搜索参数。

## 当前实现

`memory_role_separated.py` 定义独立格式 `role-separated-memory-pilot-v1`，不能交给 CG-001 的混合分支后端。
绑定同一 0.5B GGUF、C 编码器、分词模板及特征数据。使用全秩投影；无 LoRA、SVD/NAS 或 backbone 更新。

1. 初始用户 prefill 的 hidden 与来源神经特征预测三个状态，取神经网络 argmax。
   这个预测固定到本轮结束，绑定来源和参数版本，不用标签、姓名规则或答案前缀重选状态。
2. 无需记忆时，直接返回零残差，精确保留基础 C 输出。
3. 有证据时，使用神经内容读取产生的残差；来源不拼入生成 prompt。
4. 证据不足时，使用独立的 query-hidden 编码器和输出矩阵；该分支不接收来源值或分类器 hidden。
   它仍由词表概率逐 token 生成，不返回固定拒答文本。

内容输出矩阵和不确定输出矩阵零初始化；内容末层 gain 参数为 1，避免原零 gain 造成的首步输出矩阵零梯度。
这些是新随机权重，不从失败的 50 步权重继续训练。三状态分类仍依赖共享 reader 特征，不能宣称模块完全独立。

## 后置监督

前向只接收冻结 C hidden/base logits/来源特征，始终产生两条分支的分布与初始状态 logits。
标签仅决定后置 loss，不决定部署时路线。

- 状态 CE 系数为 1，只作用在初始用户 prefill。
- 有证据样例：内容分支完整回复 CE（含 EOS），不给不确定分支回答 CE。
- 证据不足样例：不确定分支完整回复 CE，不给内容分支回答 CE。
- 普通聊天：两条分支相对基础模型的 `KL(P_base || P_branch)` 取平均，不使用参考答案 CE。
- 每条回复按 token 平均，再按原样本权重汇总；4 条 batch 的总权重项除以 6（原语料均重 1.5）。

KL 使用 FP64 归一化/求和以减少近零消减，模型、特征、投影和 optimizer 参数仍为 FP32；无 AMP/TF32。
私有分类器参数没有专家生成损失的直接梯度，这由分开的计算路径保证，而不是把人为 stop-gradient
称为原联合目标的完整导数。reader 的共享特征仍同时接受相关监督，必须继续监测干扰。

分支 CE 是用参考状态选择损失的 oracle 组件诊断，不是实际路线的记忆正确率。
普通聊天的 KL 和原先参考答案 NLL 单位不同，禁止将新旧总体 loss 直接相减后宣称准确率提高。
模型选择仍使用预测路线下的真实 C 自由生成和独立评审，原基线错误和分母保持不变。
