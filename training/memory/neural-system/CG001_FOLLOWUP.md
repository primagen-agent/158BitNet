## 已有机制与待验证问题

当前三状态概率同时参与内容/不确定生成的混合，并接受完整回复 CE 的反向梯度。
状态辅助 CE 只监督初始用户前缀，但生成时每个位置重新计算状态；固定读决策是已登记的未完成项。
内容路径含从零学习的标量 gain，不确定路径的 U 则直接零初始化输出矩阵，两条路径并非相同学习速度。
不确定分支接受状态 hidden，后者包含来源特征，不能仅因名称就假设它只会学拒答。

固定面板的后置梯度诊断（`diagnose_availability_objectives.py`，不执行 optimizer）：
在第 50 步检查点，16 条中 11 条的生成 CE 与 `0.2 × 状态 CE` 对状态头的梯度余弦为负，
其中有证据的 8 条全部为负；两条中文普通算术约为 -0.948/-0.936，梯度范数之比约 1.017/0.987。
这证明这些位置存在更新方向冲突，**不证明整个训练失败只有一个原因**。
数值/语义总结果以独立生成与评分报告为准；残差范数不能单独当作贡献度或正确率。

## 下一诊断 DG-007：不加训练步数

1. 对相同检查点重放已保存的 C 特征，记录内容与不确定分支各自的 hidden/logit 增量、
   原始与换值条件的差异、初始及后续 token 状态。所有原始回复保留，禁止按结果删样例。
2. 分离三个假设：生成 loss 是否牵引任务分类；内容路径的初始化是否抑制可学习梯度；
   逐 token 重判是否使同一次回答的读决策漂移。不能一次同时改完后宣称找到了单一原因。
3. 零优化器的接口/梯度对照先验证：固定首个用户 prefill 决策不读取答案前缀；
   生成梯度被隔离后不再更新状态头，而内容/不确定输出仍有有效梯度；
   修改初始化时仍精确保留初始基础 logits，且两条分支都没有双零死梯度。
4. 无需记忆样例的目标是**不破坏基础模型**，不是逼记忆模块修复基础模型的所有算术/语言错误。
   基线错误照样报告，但将非记忆能力提升与记忆训练目标分离；不得通过改评测答案使基线通过。

## 候选修正边界

- 任务/证据判断来自当前用户 prefill 和来源的神经特征，生成期间保持本轮只读决策。
  这不是重用 backbone KV，也不能按姓名/关键词/场景 ID 设规则。
- 区分控制器的监督和生成器的监督；研究停止生成 CE 对控制概率的反向牵引。
  标签仍只进入后置 loss，不能传入 serving forward 或用 gold 选来源、分支或答案。
- 内容与不确定分支需要独立的职责约束和可比较的初始学习尺度；不得依靠不确定分支
  学会整套常识/回答风格来掩盖内容读取失败。采用何种损失与初始化须先登记、再做有界对照。
- 不引入 RAG、来源原文拼接、整句模板返回、LoRA、SVD/NAS 或 backbone 更新。
  token 级精确 payload 通道仅是既有 DESIGN 中的后续候选，不能临时绕过神经激活。
