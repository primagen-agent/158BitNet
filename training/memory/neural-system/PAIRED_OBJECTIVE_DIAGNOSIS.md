# DG-009：成对监督能否提供正确的局部学习方向

结论：**成对项增强了来源条件差异，但这套损失尚不足以证明能修复 recall。**
不能只因梯度非零、NLL 可下降，或两源差异变大就放行新训练。
同时，这也不是“原结构不可能学会”的证明；当前检查只覆盖一个检查点的局部方向。

登记：`experiments/DG-009.json`。实现：`python/diagnose_paired_memory_objectives.py`。
完整结果：`checks/DG-009-result.json`，保留每组、每个目标和全部数值核对。
原始报告 `build/neural-memory-dg009/report.json` 的 SHA-256：
`9272bfb86e3016d8d46eb6955e584e36a8e3d3cf51d675dbacbe8edfa36d6b07`。

## 1. 范围和边界

- 固定 CG-002 第 50 步权重，同一 0.5B GGUF、已校验的 C 特征包和冻结输出头。
- 预先选定训练集排序最前的四个世界 `av-002` 至 `av-005`，中英两种语言。
  共 24 条来源，8 对换值、8 对同值换主体；没有在开发集上选择损失权重。
- 换值：`original` 对 `swapped_values`。换主体：`swapped_values` 对 `wrong_subject`。
  后一组保持城市相同，不把同时改变主体和值的样本当作单因素对照。
- 初始用户 prefill 判定状态；值监督用两个参考回复首个差异值 token 的共同前缀。
  标注只进入后置损失/诊断，不进入神经读取函数；但参考前缀本身属于教师强制。
- 所有方向均为**负梯度除以其全参数 L2 范数**。因此比较的是单位参数移动的局部效应，
  不是 AdamW 更新、推荐学习率或未来训练曲线。原损失在两样本内按权重和归一化，
  保留原 2:1 权重关系，梯度范数不是原四样本 batch 的实际范数。
- 无优化器步骤、无新自由回答、无新 checkpoint；微扰后参数逐位恢复，文件哈希不变。
  不涉及 LoCoMo、LoRA、SVD/NAS、跨模型或跨 token/request KV 复用。
  冻结特征来自已有真实 C fresh-prefill；这不是新一轮实时 C 梯度或 HTTP 认证。

## 2. 比较的目标

值对照保留初始状态 CE，比较：

1. 原整句回复 CE。
2. 只在首个差异值位置计算的完整词表 CE（focused）。
3. focused 加 `softplus(1-d)`，固定系数 1，不扫描权重（paired）。

其中 `mA = zA[a]-zA[b]`、`mB = zB[a]-zB[b]`、`d=mA-mB`。
共同中心 `c=(mA+mB)/2`。两端正确要求 `mA>0` 且 `-mB>0`，不能只要求 `d>0`。
完整词表 CE 保留，因为在 a/b 两个词之间判断正确也可能输给第三个词。

主体对照比较原 2:1 加权状态/分支损失、改为 1:1 平衡，以及平衡后加同形式成对项。
这里的 m 是初始状态的“支持减不确定”logit；不在答案前缀重新决定路线。
平衡并未删除内容或拒答分支的原损失。

## 3. 固定结果

### 值：差异梯度增强，但共同变化仍占主导

| 单位负梯度方向上的观察，8 对 | 原整句 | 值位置 focused | 加成对项 paired |
| --- | ---: | ---: | ---: |
| 来源差异 d 增加 | 8/8 | 8/8 | 8/8 |
| d 的方向导数中位数 | 0.01594 | 0.03028 | 0.04997 |
| 两侧 a/b 正确 margin 同时增加 | 0/8 | 0/8 | 0/8 |
| 两侧目标对当前最强其它词的 margin 同时增加 | 8/8 | 8/8 | 8/8 |

最后一行不等于目标成为 top-1。两种来源的城市词可一起战胜当前共同错误词，
同时它们彼此之间的归属仍错误。这正是只看全词表 CE/排名改善可能漏掉的问题。
单位系数成对项确实提供额外来源敏感方向，但没有消除共享输出变化的主导作用。

### 主体：平衡权重并没有自动学会匹配

| 单位负梯度方向上的观察，8 对 | 原 2:1 | 平衡 1:1 | 平衡加成对项 |
| --- | ---: | ---: | ---: |
| 来源差异 d 增加 | 4/8 | 4/8 | 8/8 |
| d 的方向导数中位数 | 0.08288 | 0.05124 | 1.04278 |
| 两侧正确状态 margin 同时增加 | 0/8 | 0/8 | 0/8 |

成对项下，共同中心的方向导数中位数仍约 `-56.20`：局部方向主要一起降低两源的“支持”评分。
这有助于修正错主体的过度自信，但同时侵蚀正确主体的支持 margin；尚不能称为可靠主体绑定。
不能仅通过把错主体权重调大，就推断得到了条件化匹配能力。

### 不能把“两侧同时改善”错误地设为必要条件

已正确的一侧保留正 margin、另一侧从负 margin 改善，也可能逐渐获得两侧正确；
因此两侧方向导数同时为正只是一个严格的描述指标，**不是学习可行性的必要门槛**。
查看结果后补充的探索性统计（未预登记，不改变主要分母）：

- 当前较差一侧的 a/b margin：三种值目标均为 6/8 个改善；`av-002/zh` 和 `av-004/zh` 恶化。
- 当前较差一侧的主体 margin：三种主体目标均为 8/8 个改善。

这保留了原损失有纠偏能力的证据；不能将本轮解释成“完全没有有效梯度”。
也不能从这种局部趋势预测将来一定成功或一定失败。

## 4. 数值与软件检查

第一训练世界的中英两组，对值/主体各三个目标，在绝对参数 L2 半径 `0.001` 和 `0.003`
做对称微扰。每次重新前向，禁止复用参数变动前的状态决策；退出或异常均恢复原权重。
6 个 margin/差异指标，共 **144/144** 在预登记的 `atol=0.01, rtol=0.05` 内通过。
最大绝对误差 `0.01857`；这是组合容差通过，不是声称所有误差均小于 0.01。
这些核对互有关联，不是 144 个独立能力样本。

7 项新增回归覆盖后置监督、完整词表保留、权重平衡、共同比值偏置、固定竞争词、
微扰异常恢复，以及实际小型神经模块的参数/梯度不变性。
本轮 Python 回归 **182/182**，现有 build 的 CTest **21/21**。没有修改训练器或部署模型。

## 5. 后续决定

1. **保留成对监督作为候选训练要求，不将这版损失视为已完成修复。** 不调大系数追逐本面板，
   不把 8/8 梯度方向包装成 100% 记忆准确率，也不直接追加 CG-002 步数。
2. 下一项先审查并实现零训练步的 **主体/关系匹配与 token 级值读出分离接口**。
   当前 query 只有最后一行 hidden，来源有逐 token 特征；应明确是否需要新鲜 C query token 编码，
   不能把不存在的查询序列特征当作已经具备。
3. 如果引入 token 输出通道，位置和开关必须由神经状态决定；原始 token/字节仅是记忆 payload，
   不是 gold 选择器。必须先定义错主体、空记忆、重复值、跨 token 边界、未见值和关闭分支恒等测试。
   不得通过检索原文塞 prompt、正则取值、整句答案表或 teacher 路由实现“通过”。
4. 先在接口/数值层验证，再登记新的训练预算与消融：仅成对监督和增加输出通道不能混为一个根因证明。
   原两候选预算已用完；新的比较范围、步数、普通聊天/拒答退化边界和停止条件仍需正式登记复核。

当前自由生成证据仍是 CG-002 的有依据 recall **0/8**；本轮没有产生新的准确率。
单一供给事件的 reader 诊断也没有覆盖静默 writer、自动事件激活、持久化或完整 C/HTTP 链路。
