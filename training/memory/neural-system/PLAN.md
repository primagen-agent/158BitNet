## 2. 每轮工作必须遵守的流程

1. 读取本计划，确认当前阶段、未完成项与前置依赖。
2. 选择一个有明确边界的工作项，写明假设、变更范围、对照和停止条件。
3. 先固定对应接口与验收样例，再实现。
4. 先做静态/单元/数值检查，通过后才运行该阶段允许的训练或系统测试。
5. 同步 GPU 源码时保存完整快照或完整校验清单；核对模型、数据、程序哈希后运行。
6. 保存所有分母、错误样例、原始回复、配置、随机种子、检查点和结果，不只保存最好分数。
7. 根据门槛判定“通过 / 未通过 / 证据不足”，更新阶段状态与下一工作项。

如要修改模块边界、指标或数据划分，必须先更新设计与实验说明，说明原因与影响。
不允许看到结果后删除困难样例、降低门槛、改标签、换 backbone 或改成文本检索。
评分程序错误可以修正，但需保留旧报告，对所有候选一致重评并说明差异。

## 3. 依赖关系

```text
P0 设计基线
  └─ P1 契约、数据划分与评分
       ├─ P2A 事件绑定/激活 ─┐
       └─ P2B 给定正确激活的生成 ─┤
                                └─ P2C 神经激活 + 生成
                                     └─ P3 自动写入
                                          └─ P4 完整自然对话
                                               └─ P5 C/HTTP/持久化
                                                    └─ P6 独立测试与发布
```

P2A 与 P2B 可独立做归因实验。P2B 的 gold 激活仅用于诊断，不能出现在 P2C 及后续前向输入。
P2C 未过，不扩大自动写入训练。P4 未过，不把新模型接入正式 C 服务；
之前允许开发 tokenizer、特征探针、格式契约等诊断基础设施。

## 5. 验收与统计口径

以下为新阶段启动前的开发门槛，不是当前结果或已实现的服务保证。
旧 32 项诊断及其 90% 门槛原样保留，不能重命名成下面的大样本验收。

| 验收对象 | 门槛 | 必须附带的证据 |
| --- | --- | --- |
| 事件激活 | 各关键场景的目标集合准确率 ≥95% | 每场景至少 200 个独立语义世界/问题；按世界分组统计 |
| 无目标、错主体、错关系拒绝 | 错误激活率 ≤1% | 每个关键负例组至少 300 例，并报告区间 |
| 正确激活后的生成 | 主体、值、归属及限制同时正确 ≥95% | 同问题换值的两侧必须同时正确；不能只查答案子串 |
| 写入 | 关键事实召回率 ≥95%，错误事实写入率 ≤1% | 明确机会数与分母；否定/假设/引用单列 |
| 组合与端到端 | 各支持场景 ≥95%，有害错误使用率 ≤1% | 同时统计普通聊天退化、无用旁白和无依据断言 |
| 自然交流 | 未被要求的记忆操作旁白 ≤1% | 人工校验自动评分；合理代词不能一律判错 |
| 持久化/隔离/原子性 | 定义范围内回归用例 100% | 真正进程重启、错误注入及不串用户的测试 |

总体平均分不能抵消某一关键场景不达标。小样本过关只能算 smoke。
开发门槛的点估计需要置信区间；零错误的 300 个负例，单侧 95% 二项上界仍约为 1%。
模板自动评分只是小任务工具；复杂回复需按主体、关系、事实状态与证据归属评分，
并用独立人工样本校准，不能由被测模型单独裁判自己的答案。

## 6. 数据与实验治理

- 按语义世界/会话划分，而非将同一事实的改写随机分到两侧。
- 训练、开发和独立测试分别覆盖实体、值、问法、关系和长度的变化，记录哪些维度真正未见过。
- 已反复查看的 32 项只作回归；不能增加该集合的分数后声称独立泛化。
- 新实验先登记 `experiments/` 条目：假设、唯一或明确列出的变化、固定量、指标、步数与失败处理。
- 初筛最多两个对照变体，每个最多 1,000 步；扩大训练须先解释早期结果和必要性。
- 有希望的候选至少验证三个种子；单次最好种子不能代表稳健设计。
- 数据量、训练步数与结构同时改变时，明确标为多因素干预，不归因于单个因素。
- 保存自由生成文本及评分版本。检查点选择不能使用独立测试集。
- 缺少数据来源、tokenizer/模型/源码哈希或发现标签泄漏时，该轮不作为推进依据。

## 7. 偏离检测与停止条件

出现以下任一情况，停止该实验进入下一阶段，保留证据并返回对应模块分析：

- 模型通过背模板、识别人名名单、参考答案前缀或用户显式记忆命令完成任务。
- 值正确但主体/角色/时间归属错误，或用无关事件补缺失答案。
- 启用了 KV 复用、原文检索/拼接或隐藏的 gold 路由。
- 流畅生成提高，但无目标拒绝、普通聊天或持久化正确性退化。
- 只有训练重放、教师强制 NLL、单元测试或 C/Python 算子一致性，没有真实能力证据。
- 在关键前置项未通过时提前做大规模训练、LoCoMo 调参或部署替换。

失败不自动证明所有神经记忆方案都无效，但足以阻止该候选被当作可靠系统。
允许修改假设后重新立项实验，不允许无限加步数把失败改称“仍在优化”。
