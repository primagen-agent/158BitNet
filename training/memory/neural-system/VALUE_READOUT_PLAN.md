# 联合事实激活与值传递：下一阶段方案

状态：V1限定范围通过；V2字节边界、教师轨迹、自主控制器、query-only uncertainty算子接口及完整不确定回复逐token监督均已验证。uncertainty未训练，V2整体未完成，未批准新训练。
依据：`reviews/DG-014/PROCESS.md`；旧限制见 `reviews/DG-015/PROCESS.md`，新契约与证据见 `reviews/DG-016/PROCESS.md`。
本方案补充 `DESIGN.md` 与 `PLAN.md` 的P2A/P2B/P2C，不越过自动写入、生命周期和C/HTTP验收。

## 1. 保留目标，修正组件契约

模型在自然交流时决定是否需要记忆；需要时由神经激活选择内部记忆，不由用户显式调用recall。
不能做关键词/城市词典匹配、文本检索、问题到答案查表、原文拼入prompt或完整答案旁路。
确定性组件只检查身份/边界和传递已由神经模块选择的值，不替代语义选择。

分开两个任务：

1. **联合事实激活**：主体、关系、时间、肯否状态必须在同一事实表示上相容；缺少证据可选NULL。
2. **值的忠实传递**：若决定引用一个值，不能只输出名称开头，再让骨干猜剩余部分。

普通措辞仍由冻结0.5B骨干生成。不是整句copy，也不是让辅助decoder背答案。
现阶段只验证一个输入事件中含多条事实的研究接口；不声称已经完成自动写入。

## 2. 建议的新接口（传递已验证，神经预测为未训练原型）

神经模块产生reply-local `ActivatedFact`：包含模型/记忆版本绑定、预测的事实身份、值句柄、置信度和NULL状态。
句柄指向内部记忆payload，不含外部评测标签、目标答案或按问题匹配出的字符串。

- 激活分数在**同一个神经事实单元**上联合判断，不能以“任意位置存在主体 × 任意位置存在关系”作为充分条件。
- 一个事件可能包含多条事实；不能把选择正确事件当作选择正确事实。
- 事实边界、值起止与模式由网络预测；监督只进入loss，不进入推理掩码/位置。
- 只做存在性预测的两个head可保留为辅助任务，但不作为联合事实成立的保证。
- 先保持原模型作对照；不直接覆写已认证训练代码或历史checkpoint。

DG-017已实现查询条件下的联合事实跨度/条件值跨度分布、三路状态和idle开始引用head；详见 `reviews/DG-017/PROCESS.md`。
所有候选只来自结构允许位置，标签不进前向。嵌套只约束同一候选范围，不保证它恰好是一条正确事实。
事实/值的token级粗边界仍不足以表示` A`内部的A起点；需要神经细字节边界，不能用strip或目标名称规则替代。

DG-018已补充事实/值的细字节边界头，全部UTF-8合法切点由运行字节结构生成，神经评分与标签隔离。
粗组合选择后用有界链式动态规划保证四个字节端点嵌套，不创建四维笛卡尔积；属于分层解码，不保证全局联合MAP。
原4条精确标签与梯度检查现已通过，Aarhus标签不变；随机模型仍全部选择insufficient，不能声称已学会边界或记忆。

值传递模式拟分为普通生成、开始值、继续值、结束值：

- 普通生成保持原骨干旁路；神经控制器决定是否/何时进入值模式。
- 进入后固定预测的事实/值句柄，维护读取进度；在这个模式内不能跳到另一事实或让base覆盖值片段。
- 对当前连续、逐字值的试验，可用确定性游标按预测边界顺序传输；事实和值的选择仍必须由网络完成。
- 边界结束后返回普通生成；无效句柄、越界、版本变化及过长值应显式报错/拒绝，不能悄悄补词。
- 错误的预测边界仍是模型失败；游标只能保证“已选内容的传递”，不能保证选对内容。

不能直接拼接来源token ID来假设任何上下文都可复制：source和回复上下文的BPE切分可能不同。
接口需保存来源字节范围，并用同一C tokenizer校验实际输出字节/token边界。
对需要跨token重分词的情况，先定义完整的增量编码契约；不把不可表示token改为NULL后隐藏损失。
第一版只覆盖明确的连续逐字值；日期转换、单位转换、概括、多值合成和非连续值另设测试，不声称已解决。

DG-016的续接契约保持实际token前缀不变，仅对值做边界隔离的C分词，逐字节验证后追加；
临时分词标记不进入模型或回复。追加后的合法序列可不等于整串canonical BPE。
因此后续训练必须使用新实际token前缀的C特征，不能假设不同分词的隐藏态相等或直接复用旧canonical特征。

## 3. 监督必须补齐，但不能同时改完后宣称单一根因

固定旧CG-003作为失败对照。后续实验至少区分以下因素，具体训练预算另行登记/批准：

| 对照 | 改变项 | 不改变项 | 回答的问题 |
| --- | --- | --- | --- |
| 监督补全 | 值开始/继续/结束、非值copy关闭与同事实反例 | 原软混合、无游标结构 | 原结构能否仅靠监督学会忠实读出 |
| 值传递结构 | 值模式与顺序/边界约束 | 激活器和联合判定策略保持对应对照 | 是否减少覆盖、跳读、重复，是否仍复制错事实 |
| 联合激活结构 | 同一事实上的联合表示与NULL | 固定读出方案 | 是否真正拒绝角色交换、错时间/否定反例 |
| 完整组合 | 仅组合已单项验证的变更 | 骨干、数据边界、评测口径 | 自主激活后是否完整自然回答 |

新增组件无法无损复用旧权重时，必须明示初始化差异、相同训练样本/步数及可比性限制。
不能把不同初始化/不同监督/不同解码同时变化写成单因素实验；以软件oracle隔离算子与真实神经能力。
顺序损失必须保留相同token在不同位置的身份；重复字母不能仅通过token ID汇总来决定进度。
训练中存在不可复制值token、格式变化和过长值时，不删除困难样例，分别报告原因与完整分母。
真正自由生成仍是验收依据，teacher-forcing或正确句柄条件下成功不等于自主记忆成功。

## 5. 尚未解决的风险

预测事实/值边界本身可能错误；硬模式切换可能损害自然措辞；NULL可能过度拒答。
确定性传输不能弥补错误激活，神经联合激活也不能自动保证正确更新/忘记和长期容量。
小面板不足以判断0.5B容量是否足够，也不足以判断数据规模或泛化；本方案不承诺完美。
