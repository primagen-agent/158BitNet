## 检查方法

保留 DG-001 的三个样例、初始化和最后一层注入位置，只增加量化观测，不改变 backbone 算法。
C 记录 FFN 输入、FFN-down 输入及输出投影输入的真实 int8 码和 scale，以及必要中间张量。
打开观测与关闭观测的原生输出逐位相同，原生前向也与普通 C 库一致。

判定同一区间需要：正反扰动均不改变三处量化码、绝对值最大项的位置及符号，且不存在最大值并列歧义。
所有跨区间样例完整保留，不能混入“局部导数通过”的分母，也不因失败而删除。

新的 backward 不是恒等 STE。它在原生中间值处固定整数码，只通过 scale、归一化、激活及残差传递导数。
局部数学使用 float64 计算，但返回的前向仍保持真实 C float32 logits。
这不意味着已经获得有限精度程序跨所有舍入/量化边界的精确导数。

本次导数比较事前使用 `abs_error <= 0.005 + 0.25 * abs(gradient)`，并要求同号；
每例至少两个同区间对照且所有同区间对照均通过。该数值导数容差针对有限差分，
**不是**对既有前向 `atol=1e-5, rtol=1e-4` 容差的放宽。

与 DG-001 的反向相比，中文例的局部方向已翻为与本次小扰动实测一致的方向；
跨量化边界时，局部方向仍不能保证真实损失下降。
代码据真实 C NLL 筛查候选，但没有执行优化器更新。

## 更重要的结论：NLL 下降不等于记忆提取改善

按事前规则，三个例子都找到下降超过 1e-6 的最小候选（gain 减少 0.0001）。
但目标 token 排名分别仍为 **5,793、29,481、53,544**，top-1 也未改变。
全部 9 对同区间对照的 18 个端点，目标排名与 top-1 均保持不变。
logits 与原向量按输出 scale 比例缩放的最大偏差仅约 `1.88e-6`。

这一现象有直接的结构解释：在当前无输出 bias/LoRA 的冻结量化投影中，
最终整数码不变时，输出近似为 `logits = scale × 固定向量`。
正 scale 的变化可以改变 softmax 的集中程度，降低某个低概率目标的 NLL，
却不改变各候选的排序。实际 FP32 可能存在并列/舍入细节，本次已单独观察排名而非只作理论断言。

因此，本轮不能将“真实 C 损失确实下降”称为学到记忆。
这也不证明全层量化模型或所有 STE 方法都不能训练；这里只覆盖三个例子和一个 gain 方向。
后续能力验收必须同时看目标排名、自由回复、换记忆值的因果对照和无目标拒绝。

## 后续设计决策

不建议继续只靠调整局部导数追求更好 NLL。
建议另行设计一个**连续神经记忆增量分支**作对照：保留量化 backbone 基础输出，
让被神经激活的记忆通过不再次取整的连续增量影响 token 分布；关闭分支时严格保持基础输出。
该分支不能查找答案、拼接历史或直接替换回复，不得变成 RAG。

这是注入/生成路径的架构变体，不是现有全层方案已经完成：
需先确认设计变化、登记数值与梯度门槛，再做最小对照；保留当前层内注入方案作为基线。
通过数值对照后仍需 P2 的学习/因果泛化验收，不能直接接入服务或全量训练。
用户随后确认了该独立对照，DG-003 已实现并通过局部数值检查，见 `CONTINUOUS_MEMORY.md`。
DG-002 的失败记录不变；尚未验证记忆能力，EP-001 仍被拦截。

  --experiment training/memory/neural-system/experiments/DG-002.json \
