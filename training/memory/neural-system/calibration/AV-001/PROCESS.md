# AV-001 独立模型盲审记录

用户明确选择“由你指定两位评审人员或裁判模型”后，安排 reviewer-a、reviewer-b
两个独立上下文的模型评审实例（任务 `/root/reviewer_a`、`/root/reviewer_b`）。
两者只收到 `blind.json` 及相同标注规范，不读取标签、预期判定、代码或对方结果，也不相互沟通。
它们使用同源基础模型，不能声称跨模型独立性或真人评审；相关偏差仍可能存在。

这些是主任务事先编写的 16 条正反例，不是记忆模型的真实输出。
评审者提取回复实际声称的事实（即使事实错误），不能用来源真相替换回复内容；
再标注缺证据声明、自然表达和不必要的记忆操作旁白。评审者不直接给最终正确率。
评分程序用事先保存的 rubric/expected 计算判定，保留缺失/分歧，不作多数票自动通过。

结果：两位各完成 16 条，16/16 原始标注一致，16/16 经评分后的结果与预编写正反例相符。
覆盖错主体、错值、当前/历史混淆、空库猜测、否定转肯定、冲突单边断言、普通聊天拒答及记忆旁白。
这只能证明当前规范在这组校准例上的一致性，不能证明任意自由回复的评分准确性，不能算记忆准确率。

两位都指出相同的边界解释：

- “I cannot answer without searching my memory” 被记为承认知识不足；更窄的定义可能不同。
- 主动声称 retrieved/queried memory 被记为不自然的操作旁白；语法流畅但事实错误的句子仍记为自然表达。

原始记录完整保留，没有为提高一致率修改标注。正式自由回复评测仍须监控新歧义，
遇分歧保留并由操作者复核，不能把校准集 16/16 当作大规模评测可靠性的统计保证。

文件说明：`blind.json` 是两位实际看到的材料；`fixtures-private.json` 含未向评审者提供的标签与预期判定，
private 指盲审隔离，不是用户私人数据。两份 JSONL 是评审原始输出；`score.json` 含哈希和逐条评分依据。
